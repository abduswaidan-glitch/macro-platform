# الاقتصاد الكلي الأمريكي

منصة ويب عربية لمتابعة الاقتصاد الكلي الأمريكي بعين متداول NQ: النمو، وسوق العمل، والتضخم، والفائدة والعوائد،
والنقد والائتمان، والأسواق، مع بوابات NQ الكلية وتقرير يومي يكتبه Claude. البنية نفسها التي تعمل بها منصة «تدفقات الذهب».

- `index.html` صفحة المنصة (ملف واحد بلا مكتبات خارجية، تقرأ `data.json`).
- `fetch_macro.py` يجلب 29 سلسلة من FRED و3 سلاسل تموضع للدولار (COT) من Tradingster، ويفحصها، ويكتب `data.json`، ثم يكتب تقرير Claude إن حان موعده.
- `.github/workflows/update.yml` يجلب البيانات عدة مرات في كل يوم عمل ويحفظ السلاسل في `data/raw`.
- `.github/workflows/news.yml` يجلب الأخبار ويترجمها وينشر الصفحة كل 10 دقائق.
- `.github/workflows/deploy.yml` ينشر الصفحة خلال دقيقة من أي تعديل يُدفع إلى `main`.
- `data.json` لا يُحفظ في المستودع: يُبنى عند كل نشر بأحدث كود من `data/raw`.
- `config.json` حدود البوابات (العائد 10Y الحرج، VIX، العائد الحقيقي، High Yield) وإعدادات التقرير الذكي.
- `prompts/analyst.md` تعليمات المحلل الدائمة لتقرير Claude؛ عدّلها من GitHub متى شئت.

## التفعيل (مرة واحدة)

1. **الصفحة:** Settings → Pages → Source: `GitHub Actions` (النشر تقوم به ملفات `.github/workflows`، لا فرع).
   الرابط: `https://abduswaidan-glitch.github.io/macro-platform/`
2. **تقرير Claude:** Settings → Secrets and variables → Actions → New repository secret →
   الاسم `ANTHROPIC_API_KEY` والقيمة مفتاحك (نفس مفتاح منصة الذهب يعمل).
3. **أول تحديث:** Actions → «تحديث بيانات الاقتصاد الكلي» → Run workflow (فارغ = بيانات فقط؛ `manual` في report_attempt
   لتقرير يدوي مدفوع، بإذن Abdu فقط، ولا يدخل سجل التوقعات).

بيانات FRED لا تحتاج مفتاحاً (`fredgraph.csv`).

**تموضع الدولار (COT):** `macro_platform/cot.py` يقرأ تقرير CFTC لعقود USD INDEX - ICE FUTURES U.S. (098662) من صفحتي Tradingster العامتين (Legacy وTFF)، وكل صفحة تحمل التاريخ الأسبوعي منذ 2016. يُرفض الجلب إن لم يطابق تاريخ بيانات الرسم «AS OF» أو صافي الجدول صافي الرسم، فتبقى آخر نسخة سليمة. لا تُطلب الصفحة قبل موعد إصدار أحدث ممكن، وبلا انتحال متصفح. السلاسل في قسم الأوضاع المالية، ويجمعها جامعه.

## ما في الصفحة

| القسم | المحتوى |
|---|---|
| الرأس | الوقت الآن بتوقيت نيويورك وفيينا، وشريط الأرقام (10Y، والعائد الحقيقي، والدولار، وWTI، و10Y-2Y، والفيدرالي، وCore PCE، والبطالة، وVIX) |
| التنبيهات | تظهر فقط حين توجد مشكلة: «حرج» لسلسلة في خطأ يوم صدورها (من التقويم)، أو تقرير فشل مرتين، أو تعذّر قراءة الأخبار؛ و«تنبيه» لبقية الأخطاء والتقادم وتأخر الأخبار وفشل المحاولة الأولى. الفجوات المعروفة بجانب المؤشر فقط |
| الملخص | آخر تقرير باختصار وأثره على البوابات، وإشارات الدورة، وSahm Rule |
| التقرير الاقتصادي | تقرير واحد كل يوم تداول (09:00 بتوقيت نيويورك، وإعادة واحدة 12:00 بعد فشل تقني فقط): تقييم اقتصادي متصل وسيناريوهات A/B/C قابلة للقياس، وآخر 14 تقريراً. مدخلاته من جامعي الأقسام (`macro_platform/collectors.py`): جامع مستقل لكل قسم يعمل 08:40 قبل التقرير ويحفظ ملفه في `data/sections` |
| الأخبار | عناوين المصادر العامة وتقويم البيانات الأمريكية |
| النمو، والتضخم، وسوق العمل، والفيدرالي والفائدة، والأوضاع المالية | جدول لكل فئة (آخر قيمة، والتغير، وZ-score والمئوي على 5 سنوات، والزخم والمراجعات) ورسم تفاعلي لكل مؤشر. الإسكان موزّع: بدء البناء في النمو، والرهن في الفيدرالي والفائدة |
| Market Gates | NQ وS&P 500 وDow في تبويبات فرعية بمقياس −2..+2. تُكتب في استدعاء ثانٍ بعد اكتمال التقرير الاقتصادي، من التقرير نفسه وملف جامعها (أرقام مشتقة فقط). وتحت NQ حدود المنصة الحتمية وقياس الترجمة السوقية |
| المنهجية وحالة البيانات (من التذييل والتنبيه) | تعريف كل إشارة، وحالة كل مصدر وعمر آخر قيمة، وكل تحذيرات البيانات |

**مؤشرا الأسهم:** Nasdaq-100 وS&P 500 في FRED عليهما إشعار ملكية لطرف ثالث، فيُستعملان في الحساب فقط: لا تُنشر
مستوياتهما ولا رسومهما ولا يُحفظان في `data/raw`، ويُنشر المشتق منهما فقط (`data/market_derived.json`).

## سلامة البيانات

كل سلسلة تُفحص قبل النشر: تُرفض إن جاءت قصيرة أو بتاريخ أقدم من المحفوظ أو بسجل ناقص، وتبقى آخر نسخة سليمة
(`data/raw/*.csv`) مع تحذير ظاهر في الصفحة. وتُعلَّم القفزات غير المعتادة والقيم التي تجاوز عمرها التأخر الطبيعي لتكرارها.

إذا ظهر تحذير في الصفحة: Actions → آخر تشغيل → خطوة «جلب البيانات»، وانسخ السطور التي تبدأ بـ `[macro]`.

## التطوير المحلي

```bash
pip install -r requirements.txt
python -m pytest -q tests
python fetch_macro.py --demo --out /tmp/preview/data.json   # بيانات تجريبية للمعاينة (لا تُرفع)
python -m macro_platform list                                # كتالوج المؤشرات
```

المحتوى تحليلي وليس توصية شراء أو بيع.
