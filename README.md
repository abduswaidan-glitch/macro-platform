# الاقتصاد الكلي الأمريكي

منصة ويب عربية لمتابعة الاقتصاد الكلي الأمريكي بعين متداول NQ: النمو، وسوق العمل، والتضخم، والفائدة والعوائد،
والنقد والائتمان، والأسواق، مع بوابات NQ الكلية وتقرير يومي يكتبه Claude. البنية نفسها التي تعمل بها منصة «تدفقات الذهب».

- `index.html` صفحة المنصة (ملف واحد بلا مكتبات خارجية، تقرأ `data.json`).
- `fetch_macro.py` يجلب 27 سلسلة من FRED، ويفحصها، ويكتب `data.json`، ثم يكتب تقرير Claude إن حان موعده.
- `.github/workflows/update.yml` يجلب البيانات عدة مرات في كل يوم عمل ويحفظ السلاسل في `data/raw`.
- `.github/workflows/news.yml` يجلب الأخبار ويترجمها وينشر الصفحة كل 10 دقائق.
- `.github/workflows/deploy.yml` ينشر الصفحة خلال دقيقة من أي تعديل يُدفع إلى `main`.
- `data.json` لا يُحفظ في المستودع: يُبنى عند كل نشر بأحدث كود من `data/raw`.
- `config.json` حدود البوابات (العائد 10Y الحرج، VIX، العائد الحقيقي، High Yield) وإعدادات التقرير الذكي.
- `prompts/analyst.md` تعليمات المحلل الدائمة لتقرير Claude؛ عدّلها من GitHub متى شئت.

## التفعيل (مرة واحدة)

1. **الصفحة:** Settings → Pages → Source: `Deploy from a branch` → Branch: `main` و`/ (root)` → Save.
   الرابط: `https://abduswaidan-glitch.github.io/macro-platform/`
2. **تقرير Claude:** Settings → Secrets and variables → Actions → New repository secret →
   الاسم `ANTHROPIC_API_KEY` والقيمة مفتاحك (نفس مفتاح منصة الذهب يعمل).
3. **أول تحديث:** Actions → «تحديث بيانات الاقتصاد الكلي» → Run workflow (اكتب `true` في ai_force لكتابة تقرير فوراً).

بيانات FRED لا تحتاج مفتاحاً (`fredgraph.csv`).

## ما في الصفحة

| القسم | المحتوى |
|---|---|
| شريط الأرقام | 10Y، 2Y، فارق 10Y-2Y، الفيدرالي، Core PCE، البطالة، VIX، Nasdaq 100 |
| التقرير الذكي | ملخص، وانحياز NQ للجلسة، وسيناريوهات A/B/C باحتمالات مجموعها 100%، وقراءة البوابات، وأحداث اليوم بروابطها، وآخر 14 تقريراً |
| نظرة عامة | بوابات NQ (10Y مقابل الحد، VIX، العائد الحقيقي، تسعير الفيدرالي، قيادة NQ/ES، الائتمان)، وSahm Rule، ومربع النمو × التضخم |
| أقسام المؤشرات | جدول لكل فئة (آخر قيمة، التغير، Z-score والمئوي على 5 سنوات) ورسم تفاعلي لكل مؤشر (1Y/5Y/10Y/الكل) |
| المنهجية وحالة البيانات | تعريف كل إشارة، وحالة كل مصدر وعمر آخر قيمة |

## سلامة البيانات

كل سلسلة تُفحص قبل النشر: تُرفض إن جاءت قصيرة أو بتاريخ أقدم من المحفوظ أو بسجل ناقص، وتبقى آخر نسخة سليمة
(`data/raw/*.csv`) مع تحذير ظاهر في الصفحة. وتُعلَّم القفزات غير المعتادة والقيم التي تجاوز عمرها التأخر الطبيعي لتكرارها.

إذا ظهر تحذير في الصفحة: Actions → آخر تشغيل → خطوة «جلب البيانات»، وانسخ السطور التي تبدأ بـ `[macro]`.

## التطوير المحلي

```bash
pip install -r requirements.txt
python -m pytest -q tests
python fetch_macro.py --demo --out /tmp/preview/data.json   # بيانات تجريبية للمعاينة (لا تُرفع)
python -m macro_platform list                                # كتالوج المؤشرات
```

المحتوى تحليلي وليس توصية شراء أو بيع.
